How to read it

A recession quarter is R = 1 between a kept BBQ peak and trough. Shaded bands are label episodes, not NBER bands. The NBER strip is the official reference and is never used to fit the label.

Window: 1990Q1–2026Q3. The factor is estimated on the longer sample, so values near the boundary can shift slightly when data are revised; episode dates do not.

Scope, limits and provenance

This is

A frozen label audit and an exploratory walk-forward run. A way to see the label, the model probabilities and where the ensemble rule stands.

This is not

The official pre-registered result, a real-time vintage forecast, or evidence that the ensemble should ship. The exploratory run fails C-13 (Δ −0.0017, CI includes zero).

Next

Rerun under the official feature table and folds when Arshiya and Palchhin deliver. Replace the exploratory section; keep the label section.
