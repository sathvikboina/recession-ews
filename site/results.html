2 · Baselines on the frozen folds

Seed 42, fixed threshold 0.50, fitted inside each outer training block.

Supplementary

PR-AUC at 2Q prevalence is about 0.024. Ranking skill above that line is real but small.

The honest reading

The yield-curve slope is the strongest baseline at 2Q, with PR-AUC 0.156 and ROC-AUC 0.873. The plain logistic over all 149 columns does worse at 0.108, which is a warning against assuming more features help.

No baseline crosses 0.50 in the two quarters before the 2019Q4 peak, so 2Q episode recall is zero. At 4Q the slope baseline reaches PR-AUC 0.177 and detects that peak.

These are context for the official comparison, not the headline.

The ensemble is accepted only if it beats the best single model by at least 0.01 pooled PR-AUC, the paired-bootstrap 95% interval (1,000 resamples) excludes zero, and episode recall does not fall. Otherwise the best single model is primary and the ensemble is reported as a negative result. A logistic stack is exploratory only.

Why it cannot be faked

The exploratory run used four hand-built folds, a different feature set and reference implementations. Its ensemble delta was −0.0017 with a 95% interval of [−0.0550, +0.0556]. Copying those numbers into the official table would break C-13 and the project's claim discipline.

Until the run exists, this page shows no forecast.
