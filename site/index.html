Can we see a recession coming without leaking the answer?

This project separates two jobs. First it builds an ex-post recession chronology from eight official activity indicators. Then it asks whether a small set of lag-aware predictors can warn of the next peak out of sample — without ever touching the label.

Two questions, one firewall

The chronology is a measurement problem. The warning model is a prediction problem. Mixing them is the failure mode this project is built to prevent.

1 · What happened?

A dynamic factor model summarises eight coincident activity indicators. Bry–Boschan dating finds peaks and troughs; a diffusion gate keeps only broad contractions. The result is a quarterly recession flag R and an episode list.

Output: labels-v3 for the USA, labels-v1-JPN for Japan.

Validation: 4/4 NBER episodes in the USA window; 5/5 post-1994 ESRI episodes in Japan.

2 · What comes next?

A separate table turns only predictor series into lag-aware features. Availability lags are applied before transforms, scaling happens inside folds, and the label is never a column. The frozen folds score each quarter once, in time order.

Output: 147 × 149 unscaled predictor table and 67 outer folds per horizon.

Status: baselines are in; the official model result is pending.

What is established

  • The USA chronology matches all four NBER recessions with one false quarter.
  • Japan matches all five post-1994 ESRI episodes at episode level.
  • The predictor table is unscaled, lag-aware and independently firewalled.
  • Every fold is time-ordered with a purge equal to the horizon.
  • Simple baselines run on the frozen folds with no test-set tuning.

What is not established

  • Whether any model forecasts a recession out of sample.
  • Whether the pre-registered top-3 ensemble beats the best single model.
  • Any real-time claim: the data are revised history with simulated publication lags.
  • Any cross-country model result: only the USA has both labels and predictors aligned.
  • Germany: below the 6-of-8 gate, delivered as a coverage finding.
